# Java Enterprise Multi-Vendor E-Commerce Platform

## Project Overview

This project is a Java Enterprise Multi-Vendor E-Commerce Platform developed as part of the Infosys Springboard Internship.

The application allows multiple vendors to register and manage their products, while customers can browse products and purchase them through a simple web interface.

## Backend Setup

Navigate to backend folder.

```bash
cd backend
```

or

```bash
cd backend/demo
```

Run the application.

```bash
mvn spring-boot:run
```

Backend runs at:

```
http://localhost:8080
```

---

## Frontend Setup

Navigate to frontend folder.

```bash
cd frontend
```

Install dependencies.

```bash
npm install
```

Run the application.

```bash
npm run dev
```

Frontend runs at:

```
http://localhost:5173
```

---

## Database Configuration

Database: PostgreSQL

Database Name:

```
ecommerce_db
```

Configure the database in:

```
backend/src/main/resources/application.properties
```

Example:

```properties
spring.datasource.url=jdbc:postgresql://localhost:5432/ecommerce_db
spring.datasource.username=postgres
spring.datasource.password=your_password
```
